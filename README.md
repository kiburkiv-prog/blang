Blang is a simple interpeted programming language
-

The work is in progress.

# MY TARGET
I want to create an easy language without any difficult constructions and even serious optimistaions.
This language will be a good choice for tiny projects, code examples, simple scripts and learning of programming.

# STRUCTURE
The languge will consist of several parts including virtual machine (for executing the code) and the byte code translator (for preparing the code for executing).
